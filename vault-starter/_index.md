# vault

> **Read this first, every session.** Then [[DEV]] (how to work). Pull other notes only when needed: search, then read the TL;DR, then open the full note only if required.

## How this vault works
- Every note has **frontmatter + a 3-line TL;DR at the top**. Read the TL;DR first to save tokens.
- Link ideas with `[[wikilinks]]`. Concepts are shared across projects; papers and checkpoints belong to a project.
- New notes start from `templates/`. Date anything that can go stale.

## Map
- **Rules:** [[DEV]]
- **Memory:** `memory/` (who you are, feedback)
- **Concepts:** `knowledge/concepts/`
- **Projects:** `projects/<name>/overview.md`
- **Logs:** `logs/` (one per session, dated)
